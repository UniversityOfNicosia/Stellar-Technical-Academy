# Chapter I (Public Series)

An overview of what XRPL is, how it works, and what purpose(s) it serves are covered during this course. Throughout this course, an attempt to introduce the XRPL primitives, including the mission and actions of the XRPL Foundation and the built-in token XRP is made. A set of practical exercises are complementing the course enabling participants to get familiar with the theoretical concepts in a more practical way.
